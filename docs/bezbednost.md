# Безбедност симулатора

Апликација је намењена искључиво локалној и изолованој SCADA симулацији. Подразумевано нема активних API кључева, па су сви API подаци и команде заштићени.

## Улоге и кључеви

Постави одвојене дугачке случајне вредности преко променљивих окружења:

```bash
export Security__ViewerApiKey="замени-случајним-кључем-за-преглед"
export Security__OperatorApiKey="замени-случајним-кључем-за-команде"
export Security__AdminApiKey="замени-случајним-администраторским-кључем"
dotnet run --project src/Api --urls http://127.0.0.1:5080
```

Све API руте, осим `/health`, захтевају заглавље `X-Api-Key`. Кључ прегледача дозвољава GET захтеве. Операторски кључ дозвољава и управљачке команде. Администраторски кључ додатно дозвољава промену статуса инцидента.

Ради компатибилности, `Security__CommandApiKey` се и даље прихвата као операторски кључ ако `Security__OperatorApiKey` није подешен.

```bash
curl -H "X-Api-Key: $Security__ViewerApiKey" http://127.0.0.1:5080/api/plant

curl -X POST http://127.0.0.1:5080/api/plant/pump/P-101/command \
  -H "X-Api-Key: $Security__OperatorApiKey" \
  -H "Content-Type: application/json" \
  -d '{"running":true,"actor":"operator"}'
```

Контролна табла је доступна на `http://127.0.0.1:5080/`. Кључ се уноси у поље за повезивање и остаје само у меморији странице.

## Ограничења

Ово је RBAC на нивоу дељених API кључева, а не систем индивидуалних корисничких налога. Поље `actor` је податак који шаље клијент и није проверен идентитет. Ограничење броја команди се рачуна по отиску API кључа, не по клијентском пољу `actor`. Потребни су OIDC/OAuth2, појединачне дозволе, TLS, управљање тајнама, ротација кључева, ограничење захтева по стварном идентитету и централни audit за озбиљну примену.

API поставља `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer` и `Cache-Control: no-store`. Интеграциони тестови проверавају приступ по улогама, одбијање непознатих кључева и ограничење броја команди. Ово није замена за TLS и поуздану аутентификацију.

Немој излагати сервис јавној мрежи нити повезивати виртуелне команде са физичким PLC уређајима.
