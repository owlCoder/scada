# Безбедност симулатора

Овај систем је намењен искључиво локалној, изолованој симулацији.

## Управљачке команде

Све POST команде захтевају заглавље `X-Api-Key`. Кључ се поставља преко променљиве окружења `Security__CommandApiKey`. Без конфигурисаног кључа команде враћају HTTP 503. Погрешан кључ враћа HTTP 401.

```bash
export Security__CommandApiKey="замени-дугачким-случајним-кључем"
dotnet run --project src/Api --urls http://127.0.0.1:5080
```

Пример захтева:

```bash
curl -X POST http://127.0.0.1:5080/api/plant/pump/P-101/command \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: $Security__CommandApiKey" \
  -d '{"running":true,"actor":"operator"}'
```

API кључ је привремена заштита за развојно окружење, не замена за аутентификацију корисника, RBAC, TLS и управљање тајнама. Немој излагати овај сервис јавној мрежи.

## Ограничења

Стање постројења и догађаји чувају се у меморији. После рестартовања се губе. Нема комуникације са физичким PLC уређајима. Детекција учесталих команди ради по вредности `actor`, коју клијент сам шаље; зато то није поуздан идентитет оператера.
