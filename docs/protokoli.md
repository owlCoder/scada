# Виртуелна регистарска мапа

Овај модул представља регистарски модел налик Modbus holding регистрима. Садржи и опциони **Modbus TCP сервер само за читање**, који се везује искључиво за `127.0.0.1`. Не комуницира са физичким PLC уређајима.

| Адреса | Назив | Вредност | Упис |
| --- | --- | --- | --- |
| 0 | Ниво резервоара | проценат × 10 | Не |
| 1 | Пумпа P-101 | 0 = искључена, 1 = укључена | Да |
| 2 | Вентил V-101 | 0 = затворен, 1 = отворен | Да |
| 3 | Улазни проток | %/s × 100 | Не |
| 4 | Излазни проток | %/s × 100 | Не |

Читање: `GET /api/registers` или `GET /api/registers/{address}` уз кључ за преглед.

Упис: `POST /api/registers/{address}` уз кључ оператера и тело `{"value":1,"actor":"operator"}`.

Упис у регистре пролази кроз исте сервисе и заштитна правила као и команде за пумпу и вентил. ## Modbus TCP (локална симулација)

Подразумевано је искључен. За покретање:

```bash
export Protocols__ModbusEnabled=true
export Protocols__ModbusPort=1502
dotnet run --project src/Api --urls http://127.0.0.1:5080
```

Подржана је функција `03` (Read Holding Registers), са стандардним MBAP заглављем. Захтеви за упис, укључујући функцију `06`, враћају Modbus exception 01 (Illegal Function). Непостојеће адресе враћају exception 02, а неисправна дужина или број регистара exception 03.

Сервер не нуди аутентификацију на Modbus нивоу, па је **строго ограничен на loopback и само читање**. Команде за виртуелно постројење доступне су искључиво преко заштићеног HTTP API-ја. OPC UA није имплементиран.
